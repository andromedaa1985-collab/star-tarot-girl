# 用户机械塔罗牌素材

本目录包含用户通过 Lovart 调用 Midjourney 制作并提供的 22 张大阿卡那牌面和 1 张统一牌背。

只对用户原始 PNG 进行 EXIF 方向校正、RGB 转换、等比缩小和 WebP 编码；未裁切、拉伸、重绘、调整色调或替换背景。原始文件保留在用户提供的位置，不随网站发布。

- `NN-name.webp` / `back.webp`：1024 × 1536，质量优先从 82 开始，每张不超过 250 KiB。
- `NN-name-640.webp` / `back-640.webp`：640 × 960，质量优先从 80 开始，每张不超过 120 KiB。
- `NN-name-320.webp` / `back-320.webp`：320 × 480，质量优先从 76 开始，每张不超过 40 KiB。
- 等比缩放使用 LANCZOS；WebP `method=6`；不携带源文件 EXIF、ICC、XMP 元数据。
- `manifest.json` 记录源文件名、牌名映射及各尺寸的实际质量、字节数和 SHA-256，不包含用户本地目录路径。

本目录不声明任何生成提示词；它仅记录用户提供素材及其压缩衍生版本。
